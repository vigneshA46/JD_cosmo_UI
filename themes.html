Venture Kart — colour systems

Every theme below is built as a proper design system, not just recoloured. The same rules are applied to all 12 so they stay consistent across the whole app:

60 / 30 / 10 — neutral surfaces · brand · one accent Tonal brand scale 50→900, no random shades Accent = actions only (CTA, timer, active) Fixed status colours success · danger · info WCAG AA 4.5:1 text contrast, checked live White cards + 1px outline, soft shadow

References used for the rules: 60-30-10 colour rule (UX Planet, Rometheme), Material Design 3 colour roles — primary / on-primary / containers / surfaces (Android ColorScheme, Flutter M3 roles), WCAG 2.1 AA contrast.
